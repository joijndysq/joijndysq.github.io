在个人主页发布 HTML 博客与视频

博客阅读器现在同时支持 Markdown 和 HTML。HTML 文件适合需要复杂布局、原生视频或第三方播放器的文章。

方案 A：本地 MP4

将压缩后的视频放入 static/assets/video/，再使用下面的结构：

<figure class="video-block">
  <video class="local-video" controls preload="metadata"
         poster="static/assets/img/blog/demo-cover.jpg">
    <source src="static/assets/video/demo.mp4" type="video/mp4">
    你的浏览器不支持视频播放。
  </video>
  <figcaption>机械臂规划与执行演示</figcaption>
</figure>

方案 B：哔哩哔哩

将 BV_ID 替换为真实 BV 号：

<figure class="video-block">
  <div class="video-embed">
    <iframe
      src="https://player.bilibili.com/player.html?bvid=BV_ID&page=1"
      title="项目演示视频"
      loading="lazy"
      scrolling="no"
      frameborder="0"
      allowfullscreen>
    </iframe>
  </div>
  <figcaption>项目完整演示</figcaption>
</figure>

发布 HTML 博客

  1. 在 contents/blog/ 创建 HTML 片段文件。
  2. 使用 article.html?name=文件名&format=html 打开文章。
  3. 在 contents/articles.md 注册文章链接。
  4. 在 static/js/article.js 的标题映射中登记标题（可选）。
HTML 博客内容来自网站自己的仓库。不要直接粘贴来源不明的脚本、iframe 或第三方统计代码。
